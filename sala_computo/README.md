# Sala de computo: colas, prioridad y arbol de carpetas

| Archivo | Que hace |
|---|---|
| `cola_prioridad.py` | Cola normal + cola de prioridad con 3 niveles y envejecimiento |
| `simulacion.py` | Compara con y sin envejecimiento |
| `resultados_simulacion.md` | Tabla de resultados |
| `arbol_carpetas.py` | Arbol de carpetas: conteo, ruta mas profunda, listado por niveles |
| `recorridos.md` | Arbol de prueba, salida con cola y con pila, y explicacion |

## Como ejecutar

```
python cola_prioridad.py
python simulacion.py
python arbol_carpetas.py
```

Solo usa Python 3, sin librerias externas (sin `heapq` ni `collections.deque`).
