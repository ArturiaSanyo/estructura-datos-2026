# Sistema de Atención Médica

Programa en Python (consola) que administra una cola de pacientes con prioridad.

## Qué hace
- Registrar pacientes (se guardan en `pacientes.json`)
- Definir y ver reglas de priorización
- Consultar quién es el siguiente
- Atender al paciente
- Sacar a alguien de la cola
- Mostrar cuántos faltan por atender

## Cómo ejecutarlo
Necesitas Python 3 instalado.

```
python main.py
```

## Documentación (SDD)
Está en la carpeta `docs/`: constitución, especificación, plan y tareas.
