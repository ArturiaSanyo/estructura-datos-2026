# Constitución del proyecto

Reglas que guían todo el proyecto:
1. El código debe ser simple y fácil de leer (nivel principiante).
2. Todo en Python estándar, sin librerías externas.
3. Cada función hace una sola cosa.
4. Los datos se guardan en un archivo JSON.
5. El programa no debe romperse si el usuario escribe algo incorrecto.
