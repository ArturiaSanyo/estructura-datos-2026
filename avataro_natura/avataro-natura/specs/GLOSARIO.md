# Glosario para personas que no saben de tecnología

Estas son las palabras que aparecen en los documentos del proyecto,
explicadas con ejemplos de la vida diaria.

| Palabra | Qué significa | Ejemplo cotidiano |
|---------|---------------|-------------------|
| **Especificación (spec)** | Un texto que dice **qué** debe hacer una parte del programa, sin decir cómo | El pedido que le haces a un restaurante: "quiero una sopa caliente" |
| **Plan** | Un texto que dice **cómo** se va a lograr lo que pide la especificación | La receta que sigue el cocinero |
| **Tareas** | La lista de pasos pequeños para construir algo | La lista de pasos de la receta, con casilla de "hecho" |
| **Criterio de aceptación (CA)** | Una frase que se puede comprobar con un "sí cumple / no cumple" | "La sopa llega caliente" se puede comprobar; "la sopa es rica" no |
| **Prueba** | Un mini-programa que comprueba un criterio y avisa si pasa o falla | Probar la sopa con un termómetro |
| **Trazabilidad** | El camino que une una necesidad con su criterio, su prueba y su código | Poder seguir el hilo desde el pedido hasta el plato servido |
| **Estructura de datos** | Una forma de organizar información para usarla rápido | Un archivador, una fila de banco, el índice de un libro |
| **Árbol** | Información organizada con ramas: cada elemento puede tener "hijos" | Una conversación donde cada mensaje puede tener respuestas |
| **Cola** | Los elementos salen en el mismo orden en que llegaron | La fila del banco: quien llega primero se atiende primero |
| **Tabla de dispersión (hash)** | Un archivador con casilleros numerados: un cálculo rápido dice en cuál casillero está cada cosa | El índice de un libro: vas directo a la página sin hojear todo |
| **Nodo** | Una pieza de una estructura, unida a otras piezas | Un eslabón de una cadena |
| **Complejidad O(1)** | Tarda más o menos lo mismo, sin importar cuántos elementos haya | Abrir la gaveta número 7 de un archivador, tenga 10 o 10 000 gavetas |
| **Complejidad O(n)** | Tarda más cuantos más elementos haya (crece en proporción) | Leer un libro de principio a fin: el doble de páginas, el doble de tiempo |
| **Invariante** | Algo que siempre debe ser verdad, pase lo que pase | "El saldo de la cuenta nunca es un número con letras" |
| **Error propio** | Un aviso con nombre específico cuando algo sale mal | El mensaje "Producto agotado" en lugar de un error genérico |
| **Docstring** | El texto explicativo que va dentro del código, debajo del nombre de una función | La etiqueta con instrucciones pegada a un electrodoméstico |
| **Commit** | Una "foto" guardada del proyecto en un momento dado | Guardar una versión del documento con fecha y nota |
| **MoSCoW** | Una forma de ordenar lo importante: Must (indispensable), Should (importante), Could (si sobra tiempo), Won't (no en este proyecto) | Lista de compras: lo urgente, lo conveniente, lo opcional y lo que hoy no se compra |
